# Project Description

**The Inkverse** is a browser-based literary exploration game that teaches players about poetry, Gothic fiction, satire, Modernism, postcolonial literature, ancient classics, and magic realism — through gameplay rather than lectures.

Players navigate a mysterious library, entering themed rooms where each challenge tests and teaches a different literary concept. An XP system unlocks harder rooms as knowledge grows.

Built in pure HTML, CSS, and JavaScript — no frameworks, no dependencies, no build tools. The entire game lives in a single file. Open it in a browser and it runs.

---

**Key features:**
- 7 literary rooms covering major movements from Homer to Borges
- 35 hand-crafted questions with detailed explanations after each answer
- 5 question types: Finish the Line, Hidden Meaning, Who Wrote It?, Write Like the Genre, Literary Device
- XP and unlock system that rewards progress
- Atmospheric dark-library visual design with Google Fonts
- Zero dependencies — one file, works offline

**Intended audience:** Curious readers (16+) exploring literature before committing to formal study. Also suitable for A-level / undergraduate revision.

**Portfolio value:** Demonstrates DOM manipulation, game state logic, CSS animations, typography, and UI design — all in one project.
